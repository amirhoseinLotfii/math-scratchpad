# دفتر ریاضی Math Scratchpad

ویرایشگر لمسی ریاضی با React، TypeScript و Redux Toolkit؛ برای نوشتن مستقیم روی خود فرمول و نگهداری مراحل حل.

[English](README.md) · [معماری](docs/architecture.md) · [سیستم طراحی](docs/design-system.md) · [برنامه توسعه](ROADMAP.md)

## امکانات این نسخه

- انتخاب مستقیم صورت، مخرج، عملگر و جای نشانگر در عدد چندرقمی؛ ریاضی همیشه LTR و با ارقام ASCII است.
- لمس نقطه کنار کسر برای درج روی خط اصلی، خارج از صورت و مخرج.
- صفحه‌کلید جمع‌وجور، حالت کامل، نمادها بر اساس موضوع، محبوب‌ها و چهار نماد اخیر.
- کلید Next برای حرکت میان خانه‌های کسر، توان، انتگرال و دیگر الگوها و سپس خروج از آن‌ها.
- انتخاب کل ساختار، کپی و برش داخلی، چسباندن، تکثیر و حذف؛ همراه Undo/Redo.
- دفتر چندمرحله‌ای، خط جدید خالی، علامت پاسخ نهایی و حفظ مراحل بعدی با برچسب نیاز به بازبینی.
- تبدیل عبارت فعلی به صورت مسئله یک تمرین تازه، با حفظ تمرین قبلی.
- ذخیره محلی در صورت پشتیبانی میزبان و پشتیبان JSON برای انتقال تمرین.
- دکمه Check متن مسئله و تمام مراحل را کپی می‌کند تا خودتان در گفتگو بچسبانید و ارسال کنید. بعد از تغییر، هشدار Changed since copy نمایش داده می‌شود.

## اجرا و بررسی

Node.js 24 و npm لازم است:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

خروجی build شامل نسخه استاندارد، فایل مستقل و قطعه آماده ادغام در میزبان پشتیبان است. نمایش تعاملی داخل گفتگو به قابلیت اجرایی همان میزبان نیاز دارد؛ چسباندن کد در یک پیام معمولی آن را اجرا نمی‌کند. این پروژه به سرور MCP یا کلید API احتیاج ندارد.

## نکات مهم استفاده

برای انتخاب کل یک کسر، ابتدا یکی از خانه‌هایش را لمس کنید و سپس Structure را بزنید. برای جابه‌جایی، Cut را بزنید، جای جدید را انتخاب کنید و Paste را بزنید. این کپی مخصوص ساختار ریاضی و داخلی است؛ دکمه Check متن کامل قابل ارسال را در کلیپ‌بورد سیستم قرار می‌دهد.

اگر کپی خودکار مجاز نباشد، متن آماده انتخاب و کپی دستی نشان داده می‌شود. هیچ ارسال خودکار یا بررسی محلی جواب انجام نمی‌شود. خط بدون نشان Final پاسخ نهایی فرض نمی‌شود.

پشتیبانی از موضوعات پیشرفته در این نسخه به معنی درج و ویرایش نماد و الگو است. حل نمادین، رسم نمودار، تشخیص دست‌خط و تبدیل خودکار توضیح فارسی به فرمول پیاده‌سازی نشده‌اند. واردکردن LaTeX محدود و صریح است؛ برای انتقال بدون افت، از Session backup استفاده کنید.

آزمون‌های خودکار اجرا می‌شوند، اما آزمون لمس و پوشانده‌نشدن کنترل‌ها در اپ اندروید باید روی دستگاه واقعی انجام شود. [گزارش بررسی](docs/qa.md) محدودیت‌ها را مشخص می‌کند.

اگر تجربه کار با آن برایتان مفید بود، Star به دیده‌شدن پروژه و Watch بخش Releases به دریافت خبر نسخه‌ها کمک می‌کند. مشارکت و گزارش ایراد واقعی خوشایند است.
