# دفتر ریاضی Math Scratchpad

دفتر تعاملی متن‌باز برای حل مرحله‌به‌مرحلهٔ ریاضی، با ویرایش مستقیم کسرهای عمودی، میان‌بُرهای کیبورد، چیدمان واکنش‌گرا و آزمون تشخیصی ۳۰سؤالی بدون راهنمای پاسخ.

[English](README.md) · [معماری](docs/architecture.md) · [سیستم طراحی](docs/design-system.md) · [برنامه توسعه](ROADMAP.md)

## نسخهٔ ۰٫۵٫۱ — پایداری و اصلاح ارزیابی

- **تشخیص درست کسر منفی ساده‌شده:** مانند `−1/8` که دیگر اشتباهاً «نیازمند ساده‌سازی» اعلام نمی‌شود.
- **حذف قابل پیش‌بینی:** در نقطهٔ بین دو عنصر، Delete عنصر بعدی و Backspace عنصر قبلی را هدف می‌گیرد؛ Undo تغییر را برمی‌گرداند.
- **آزمون بی‌راهنما:** چند عبارت اشاره‌کننده به روش حل از متن سؤال حذف شدند.
- **تست رگرسیون:** برای کسرهای منفی، عبارت مبهم و حذف ساختاری آزمون اضافه شد.

همان **۳۰ سؤال در یک دفتر ثابت** با Next/Previous، صورت سؤال فارسی، ریاضی و دکمه‌های انگلیسی/LTR، و صفحه‌کلید کناری قابل‌جمع‌شدن حفظ شده است. تأیید عملی روی دستگاه‌های واقعی هنوز لازم است.

[متن معرفی به‌روز](docs/ANNOUNCEMENT.md) · [متن تبلیغاتی آماده](docs/launch-posts.md)

## نسخهٔ ۰٫۵ — آزمون جامع کسرها و نوشتن با کیبورد

- **۳۰ سؤال تشخیصی بدون راهنمایی:** صورت سؤال‌ها فارسی هستند، ولی کنترل‌های ویرایشگر انگلیسی و فرمول‌ها کاملاً LTR نمایش داده می‌شوند.
- **یک دفتر ثابت:** دکمه‌های Previous و Next بین سؤال‌ها حرکت می‌کنند؛ مراحل و پاسخ هر سؤال جدا حفظ می‌شود، بدون ایجاد دفتر تازه.
- **دسکتاپ و موبایل:** صفحه‌کلید اختیاری در دسکتاپ کنار دفتر قرار دارد، در موبایل زیر آن می‌آید، و در حالت بسته دفتر تمام‌عرض است.
- **ناوبری ساختاری:** فلش چپ/راست میان اجزای هم‌سطح و فلش بالا/پایین میان صورت و مخرج همان کسر. منوی درج با جهت‌ها، Enter و Escape کار می‌کند.
- **حذف و Undo/Redo:** حذف ساختار انتخاب‌شده و برگرداندن تغییرات با میان‌بُرهای متداول.
- **ارزیابی مقدماتی با اعداد گویا:** درست‌بودن مقدار، ساده‌بودن کسر و سازگاری تساوی‌ها جدا گزارش می‌شود؛ ساختار مبهم «نیازمند بازبینی» است، نه لزوماً پاسخ غلط.
- **حریم خصوصی:** دادهٔ تمرین فقط در مرورگر ذخیره می‌شود، اگر ذخیره‌سازی مجاز باشد؛ بکاپ JSON برای انتقال در دسترس است.

`Check` همچنان صرفاً مراحل را برای بررسی کپی می‌کند. قابلیت تشخیصی جداگانه محاسبات را به‌صورت مقدماتی ارزیابی می‌کند و جای بررسی انسانیِ استدلال را نمی‌گیرد.

برای امتحان نسخه: `npm ci && npm run dev` و سپس **Menu → Start 30-question diagnostic**.

## امکانات این نسخه

- انتخاب مستقیم صورت، مخرج، عملگر و جای نشانگر در عدد چندرقمی؛ ریاضی همیشه LTR و با ارقام ASCII است.
- لمس نقطه کنار کسر برای درج روی خط اصلی، خارج از صورت و مخرج.
- صفحه‌کلید جمع‌وجور، حالت کامل، نمادها بر اساس موضوع، محبوب‌ها و چهار نماد اخیر.
- کلید Next برای حرکت میان خانه‌های کسر، توان، انتگرال و دیگر الگوها و سپس خروج از آن‌ها.
- انتخاب کل ساختار، کپی و برش داخلی، چسباندن، تکثیر و حذف؛ همراه Undo/Redo.
- دفتر چندمرحله‌ای، خط جدید خالی، علامت پاسخ نهایی و حفظ مراحل بعدی با برچسب نیاز به بازبینی.
- تبدیل عبارت فعلی به صورت مسئله یک تمرین تازه، با حفظ تمرین قبلی.
- ذخیره محلی در صورت پشتیبانی میزبان و پشتیبان JSON برای انتقال تمرین.
- دکمه Check متن مسئله و تمام مراحل را کپی می‌کند تا خودتان در گفتگو بچسبانید و ارسال کنید. بعد از تغییر، هشدار Changed since copy نمایش داده می‌شود.

## اجرا و بررسی

Node.js 24 و npm لازم است:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

خروجی build شامل نسخه استاندارد، فایل مستقل و قطعه آماده ادغام در میزبان پشتیبان است. نمایش تعاملی داخل گفتگو به قابلیت اجرایی همان میزبان نیاز دارد؛ چسباندن کد در یک پیام معمولی آن را اجرا نمی‌کند. این پروژه به سرور MCP یا کلید API احتیاج ندارد.

## نکات مهم استفاده

برای انتخاب کل یک کسر، ابتدا یکی از خانه‌هایش را لمس کنید و سپس Structure را بزنید. برای جابه‌جایی، Cut را بزنید، جای جدید را انتخاب کنید و Paste را بزنید. این کپی مخصوص ساختار ریاضی و داخلی است؛ دکمه Check متن کامل قابل ارسال را در کلیپ‌بورد سیستم قرار می‌دهد.

اگر کپی خودکار مجاز نباشد، متن آماده انتخاب و کپی دستی نشان داده می‌شود. هیچ ارسال خودکاری انجام نمی‌شود؛ فقط در آزمون تشخیصی، ارزیابی عددی مقدماتی و محلی در بخش Finish ارائه می‌شود. خط بدون نشان Final پاسخ نهایی فرض نمی‌شود.

پشتیبانی از موضوعات پیشرفته در این نسخه به معنی درج و ویرایش نماد و الگو است. حل نمادین، رسم نمودار، تشخیص دست‌خط و تبدیل خودکار توضیح فارسی به فرمول پیاده‌سازی نشده‌اند. واردکردن LaTeX محدود و صریح است؛ برای انتقال بدون افت، از Session backup استفاده کنید.

آزمون‌های خودکار اجرا می‌شوند، اما آزمون لمس و پوشانده‌نشدن کنترل‌ها در اپ اندروید باید روی دستگاه واقعی انجام شود. [گزارش بررسی](docs/qa.md) محدودیت‌ها را مشخص می‌کند.

اگر تجربه کار با آن برایتان مفید بود، Star به دیده‌شدن پروژه و Watch بخش Releases به دریافت خبر نسخه‌ها کمک می‌کند. مشارکت و گزارش ایراد واقعی خوشایند است.
