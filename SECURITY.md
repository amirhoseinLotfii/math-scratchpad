# Security

Do not post credentials, private exercise data or sensitive session exports in public issues. For a suspected vulnerability, use the repository's private vulnerability reporting option if enabled. Otherwise open a minimal issue requesting a private contact path without publishing exploit details or private data.

The editor makes no model or analytics requests. Clipboard writes happen after a user action. JSON sessions are bounded and reconstructed through allowlisted fields; they are never evaluated as code. Keep dependency updates and lockfiles under review.

This prototype is not a high-stakes mathematical verification system.
