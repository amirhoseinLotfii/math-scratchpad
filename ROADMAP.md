# Roadmap

## Shipped in 0.3.0

- React + TypeScript with Redux Toolkit state and document history.
- Direct math editing, explicit LTR, measured digit caret and main-line boundaries.
- Compact/full keyboard, structural Next, internal structure clipboard.
- New problem from expression, recent/favorite symbols and copied-snapshot tracking.
- Portable session format with v1 migration, tests and production builds.

## Next: validate before expanding

- Real Android ChatGPT host testing at 320, 360, 412 and 768 CSS px.
- TalkBack labels, focus movement and clipboard fallback behavior.
- Property-based AST operation testing and deeper nested-expression navigation.
- Full paste roundtrip for every exported LaTeX template.
- Continuous browser-based mobile regression tests when a browser runner is available.

## Explore with explicit product decisions

- Interactive graphing with editable function input.
- Handwriting or photo input with a mandatory correction step.
- Optional symbolic engine with domain-aware feedback.
- Host-authorized review responses attached to a step.
- Sync across devices through a user-chosen storage provider.

These items are plans, not implemented features or delivery promises.
